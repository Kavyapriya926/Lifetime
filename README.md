# LifeTime Financial Exchange Landing Page

A responsive single-page landing page for LifeTime — India's Financial Exchange — built with HTML5, CSS3, jQuery, and Font Awesome icons.

## Project Structure

```text
lifetime-financial-exchange/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
│   └── .gitkeep
└── README.md
```

## Features

- Premium fintech landing page design
- Responsive layout for desktop, tablet, and mobile
- Hero section with custom financial ecosystem illustration
- Early access form with jQuery validation
- Success message without sending data anywhere
- Animated section reveals and button hover effects
- Mobile menu and smooth scrolling
- Clean, commented HTML and CSS structure for beginners

## Run Locally in VS Code

1. Open this folder in VS Code.
2. Open the file `index.html`.
3. Install the Live Server extension if it is not already installed.
4. Right-click on `index.html` and select `Open with Live Server`.
5. Your landing page will open in the browser.

Alternatively, you can run a simple local server from the terminal:

```bash
cd lifetime-financial-exchange
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
